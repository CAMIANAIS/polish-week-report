# Demo script (5 minutes)

| Time | Section | What I say / show |
|---|---|---|
| 0:00–0:30 | Who I am + what I did | "This week I reviewed my 4 projects as if I were the evaluator, and fixed what I found." |
| 0:30–1:00 | How I reviewed | Ran lint, build and tests, used each app as a user, compared my docs against my code |
| 1:00–2:30 | **Main story: overselling** | Draw the timeline → show the failing test → the fix → the passing test → the decision (refund vs reservation) |
| 2:30–3:30 | Frontend fix | Before/after GIF of the Update button or the search debounce; why I chose that model |
| 3:30–4:15 | How I used AI | One time it was wrong and how I caught it; what I do differently now |
| 4:15–5:00 | What I learned + next | 3 lessons, 1 thing I'd still improve |

## Tips
- Speak slowly. Pausing is better than filler words.
- Show the test, not just the code. Tests are proof.
- Close with "Any questions?" and then stop talking.
